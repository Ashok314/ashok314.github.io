The logo background contains exactly the first 12,721 numerical digits of pi. The decimal point is not counted as a digit.

The round `logo.svg` and `favicon.svg` arrange the digits in concentric rings and are generated by `_scripts/generate_logo.rb`. The original Canva animation remains available as `logo_1.gif`.

Reference: [100,000 Digits of Pi](http://www.geom.uiuc.edu/~huberty/math5337/groupe/digits.html)
